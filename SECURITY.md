# Security Policy

Only the latest commit on the default branch is supported.

Report security concerns through GitHub private vulnerability reporting when available. Do not place credentials, private registry names, cluster details, production manifests, or sensitive scan evidence in public issues.

The `fixtures/vulnerable` directory is intentionally insecure, non-deployable test data. Findings that merely restate those documented weaknesses are expected; vulnerabilities in the analyzer or CI controls remain in scope.
